# Context Efficiency Protocol

1. **Strict Context:** Do not guess code outside the files provided via @.
2. **Minimalism:** Provide concise answers. Focus on logic, not boilerplate.
3. **New Session:** If the user starts a new task, remind them to use a clean chat (Cmd+L) if the current history is too long.
4. **Token Saving:** Prefer explaining logic over generating massive repetitive blocks of code unless explicitly requested.
